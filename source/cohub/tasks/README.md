# Tasks

The name in the first column is what `--task` takes.

## Tasks with two agents

| Task | Description |
|---|---|
| `cocarry` | two robots carry a basket and set it down level |
| `handover` | one robot passes a bottle to the other across a counter |
| `framehang` | two robots lift a framed picture and hang it on a wall peg |
| `pouring` | Robot A tips a marble into the glass Robot B holds |
| `copouring` | both robots lift a tub of apples and pour it into a crate |
| `trashcollection` | Robot A brings the bin, Robot B sweeps the litter into it |
| `cartservice` | Robot A pushes a cart to a table, Robot B serves the bottle from it |
| `tablealign` | two robots carry a table to a chair and set it down square |

## Tasks with three agents

| Task | Description |
|---|---|
| `movehouse` | Robot A holds a door open while B and C carry a table through |
| `bigtable` | three robots carry a round table across a room |
